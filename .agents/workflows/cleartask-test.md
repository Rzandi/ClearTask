---
description: Periksa dan jalankan test ClearTask yang relevan, laporkan hasil apa adanya
---

1. Baca package.json, cari script test yang ada. Jangan mengarang command.
2. Tentukan test yang relevan dengan file yang berubah (git status / git diff --stat).
3. Jalankan test itu. Catat command persis dan outputnya.
4. Laporkan: lolos, gagal (dengan pesan error), dan area penting yang belum ada test-nya.
5. Jangan klaim berhasil kalau test belum dijalankan. Kalau gak bisa dijalankan, bilang alasannya.
6. Jangan ubah kode atau test kecuali diminta.
